🚀 **InnovaX – Innovation Social Platform**

❌ A modern web-based platform designed to connect students and industry professionals through innovation, collaboration, and real-world opportunities.

💡 Key Features:

* Innovation post sharing (projects, ideas, research)
* Interactive feed with likes, comments, and engagement
* User profiles with skills, portfolio, and achievements
* Course & video-based learning integration
* Real-time style navigation and clean UI experience

🎯 Built using HTML, CSS, and JavaScript (UI phase), with future backend integration using PHP & MySQL.

🌐 Vision: To bridge the gap between student innovation and industry demand.
